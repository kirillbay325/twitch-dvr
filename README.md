## Что это

**Twitch DVR Player** — расширение для Chromium-браузеров, которое делает из прямого эфира полноценный плеер с перемоткой. Больше не нужно открывать вкладку «Видео», искать текущую трансляцию и мириться с кривым плеером VOD.

Расширение работает с **записью текущей трансляции**, которую Twitch создаёт во время эфира. Из этой записи берётся максимальное доступное качество (обычно source — 1080p, а если стример вещает в 2K, то и 2K), а таймлайн позволяет перематывать на любой момент уже прошедшего эфира.

> Важно: расширение **не обходит сетевые ограничения** и не использует VPN/прокси. Оно воспроизводит запись, которую Twitch и так отдаёт, и добавляет к ней DVR-интерфейс.

## Возможности

| Возможность | Что делает |
| --- | --- |
| **Полный DVR** | Таймлайн всей текущей трансляции, пауза, перемотка назад и кнопка «К эфиру». |
| **Максимальное качество** | По умолчанию выбирается source из записи текущего эфира; вручную можно выбрать 720p, 480p и ниже. |
| **DVR без VOD-страницы** | Всё происходит на странице канала. Чат Twitch остаётся на месте. |
| **DVR без записей** | Если VOD отключён, включается локальный live-буфер: перемотка доступна с момента открытия канала. |
| **Буфер 5–30 минут** | Размер локального буфера выбирается в настройках; старые фрагменты удаляются автоматически. |
| **Кнопка DVR в нативном плеере** | В стандартном плеере кнопка встроена в правую нижнюю панель, левее шестерёнки. Если панель недоступна — остаётся запасная кнопка в углу. |
| **Понятный звук** | Клик по динамику выключает звук и уводит ползунок в 0; иконка показывает уровень громкости одной, двумя или тремя волнами. |
| **Спокойный интерфейс** | Графитовая палитра, steel-blue акцент, плавные анимации и аккуратный плавающий control-dock. |
| **Безопасный fallback** | Если ни VOD, ни live-буфер запустить не удалось, остаётся стандартный плеер и кнопка DVR. |
| **Никакой телеметрии** | Все запросы идут только к Twitch; сторонней аналитики нет. |

## Как это работает

1. Расширение определяет живой канал и проверяет, доступна ли запись текущей трансляции.
2. Если запись доступна, она воспроизводится почти как live: HLS-сегменты подгружаются по мере появления, а таймлайн покрывает весь эфир.
3. Если записи нет, расширение скачивает live-сегменты само и складывает их в локальный буфер IndexedDB. Перемотка доступна с момента открытия канала.
4. Рекламные вставки Twitch в локальный буфер не попадают и пропускаются. Во время рекламной паузы плеер ждёт продолжения или показывает уже сохранённый контент.
5. При перемотке расширение либо запрашивает более старые сегменты записи, либо читает сохранённый live-буфер.
6. В меню качества показываются доступные дорожки: source и транскоды Twitch.
7. DVR-плеер живёт в том же месте, где был обычный: чат, театральный режим и остальная страница не ломаются.

В режиме записи видео идёт примерно **на 15–30 секунд позже настоящего live**. В режиме локального буфера задержка меньше, но история ограничена размером буфера и начинается с момента входа.

## Требования

| Что нужно | Подробности |
| --- | --- |
| **Браузер** | Chromium **111+**. |
| **Twitch** | Канал в эфире. Записи VOD желательны, но не обязательны. |
| **Каналы без VOD** | Вкладка с каналом должна быть открыта: расширение записывает live локально. Буфер на 5–30 минут занимает место на диске. |
| **Интернет** | Стабильный канал под bitrate выбранного качества. Для source 1080p60 обычно нужно около 8 Мбит/с. |
| **Дополнительные программы** | Не требуются. Node нужен только для пересборки CSS при разработке. |

> Если VOD отключён или доступен только подписчикам, расширение включает локальный live-буфер. История в этом режиме начинается с момента открытия канала, а не с начала эфира.

## Установка

Расширение ставится как **unpacked**-расширение. В магазине расширений его нет; для локальной установки это нормальный и безопасный способ.

### Вариант 1. Скачать ZIP

1. Откройте [репозиторий](https://github.com/kirillbay325/twitch-dvr).
2. Нажмите **Code → Download ZIP**.
3. Распакуйте архив в постоянную папку, например `%USERPROFILE%\twitch-dvr`. Не оставляйте расширение в папке загрузок, если потом чистите её.
4. Внутри архива будет папка вида `twitch-dvr-main` — при установке выбирайте её или переименуйте в `twitch-dvr`. Главное, чтобы `manifest.json` лежал прямо в выбранной папке.

### Вариант 2. Клонировать через git

```bash
git clone https://github.com/kirillbay325/twitch-dvr.git
```

Папка `twitch-dvr` с `manifest.json` внутри и будет папкой расширения.

### Установка в Chromium

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика** (Developer mode) в правом верхнем углу.
3. Нажмите **Загрузить распакованное расширение** (Load unpacked).
4. Выберите папку `twitch-dvr` (в ней должен лежать `manifest.json`).
5. Откройте канал на Twitch и обновите страницу: `Ctrl+F5`.

### Проверка установки

- На канале в эфире появится DVR-плеер с таймлайном и плавающей панелью управления.
- Если открыт стандартный плеер Twitch, кнопка **DVR** будет в правой нижней панели, левее шестерёнки. Если нативная панель недоступна — кнопка появится в правом верхнем углу видео.
- В настройках DVR-плеера (иконка с ползунками) внизу должна быть строка **«Версия 1.3.0»**.

> Выбирайте именно корневую папку расширения, а не `src` и не папку с архивом. Браузер должен видеть `manifest.json` сразу внутри выбранной папки.

## Обновление

1. Откройте `chrome://extensions`.
2. Найдите **Twitch DVR Player** и нажмите значок обновления на карточке.
3. Полностью обновите вкладку Twitch: `Ctrl+F5`.
4. Проверьте версию в настройках плеера.

Если версия не меняется, удалите расширение и загрузите папку заново: Chromium-браузеры иногда кешируют unpacked-расширения. Актуальная версия — **1.3.0**.

## Использование

### Кнопка DVR в стандартном плеере

Когда показан обычный плеер Twitch, кнопка **DVR** встроена в правую нижнюю группу управления — **левее шестерёнки**. Нажмите её, страница перезагрузится, и включится DVR-плеер.

Если нативная панель не отрисовалась или Twitch изменил разметку, кнопка **DVR** останется в правом верхнем углу видео как запасной вариант.

Когда DVR-плеер активен, нативная панель скрыта. Чтобы вернуться к стандартному плееру, откройте настройки DVR (иконка с ползунками) и выберите **«Стандартный плеер Twitch»**.

### Управление

| Элемент | Действие |
| --- | --- |
| Таймлайн | Перемотка по текущей записи или локальному live-буферу; подсказка показывает время. |
| Кнопка **LIVE / К ЭФИРУ** | Возвращает к последнему доступному моменту эфира. |
| Play / Pause | Пауза и продолжение. |
| Меню качества | Source и транскоды в режиме записи; live-качество в локальном буфере. |
| Динамик и ползунок | Громкость и mute; иконка меняет уровень. |
| Fullscreen | Полноэкранный режим DVR-плеера. |
| Настройки | Стандартный плеер, перезапуск DVR, размер локального буфера, информация о задержке и версии. |

### Каналы без VOD

Если у стримера отключены записи, DVR всё равно работает — в режиме локального буфера:

- перемотка доступна **с момента открытия канала**, а не с начала трансляции;
- размер буфера выбирается в настройках: **5, 10, 20 или 30 минут** (по умолчанию 10);
- качество — то, что Twitch отдаёт в live (в РФ часто 720p, но некоторые каналы отдают 1080p);
- буфер хранится локально в IndexedDB, старые фрагменты удаляются автоматически;
- рекламные вставки Twitch пропускаются; на время рекламы воспроизведение ждёт продолжения, а индикатор может показать **РЕКЛАМА**;
- после перезагрузки страницы, переключения на стандартный плеер или смены качества буфер начинается заново.

> Буфер живёт только пока открыта вкладка канала. Для полной истории эфира без VOD нужен внешний рекордер, работающий с начала трансляции.

### Звук

- Нажмите на динамик — громкость плавно уйдёт в **0%**, ползунок опустится, а иконка станет перечёркнутой.
- Повторное нажатие вернёт прежнюю громкость.
- Пока звук включён, иконка показывает уровень: одна волна — тихо, две — средне, три — громко.
- Ползунок громкости работает так же и синхронизирован с иконкой.

## Качество и задержка

- Twitch ограничивает качество **прямого эфира** для зрителей из России. На практике потолок часто составляет 720p.
- Запись текущей трансляции при этом может отдавать **source**: 1080p60 или 2K, если стример вещает в таком качестве.
- В режиме локального буфера качество ограничено тем, что отдаёт live: обычно 720p, иногда 1080p. Source-дорожка из записи в этом режиме недоступна.
- Расширение по умолчанию выбирает максимальную доступную дорожку. Если интернет не тянет source, выберите 720p60 в меню качества.
- 2K/1440p появится **только если сам стример вещает в 2K**: Twitch не создаёт 2K-транскоды.
- В режиме записи DVR-плеер идёт на **15–30 секунд позже** настоящего live. В режиме локального буфера задержка меньше, но во время рекламных пауз воспроизведение ждёт продолжения.

## Ограничения

- Записи «только для подписчиков» не поддерживаются без авторизации: расширение переходит в режим локального live-буфера.
- Локальный буфер работает, только пока открыта вкладка канала. После перезагрузки, смены качества или переключения на стандартный плеер он начинается заново.
- История без VOD начинается с момента открытия канала; перемотать то, что было до входа, нельзя. Для полной истории нужен внешний рекордер.
- Локальный буфер занимает место на диске: в 720p60 это примерно 250–350 МБ за 10 минут, в 1080p60 — больше. Размер ограничивается настройкой 5–30 минут.
- В локальном буфере нет source-качества из записи: доступно только live-качество (обычно 720p, иногда 1080p).
- Рекламные вставки Twitch пропускаются; во время рекламы воспроизведение ждёт продолжения. Реклама, оверлеи расширений Twitch, опросы, клипы поверх видео и другие слои стандартного плеера не отображаются — для них переключитесь на стандартный плеер.
- В режиме записи это не способ смотреть «настоящий live» в 1080p: используется запись, поэтому есть задержка.
- Расширение не использует VPN/прокси и не обходит ограничения Twitch.
- Поддерживаются Chromium-браузеры для десктопа. Firefox и мобильные браузеры не поддерживаются.
- Twitch периодически меняет API и разметку. Если расширение перестало работать, проверьте обновления и консоль с фильтром `[TwitchDVR]`.

## Решение проблем

| Симптом | Причина | Что сделать |
| --- | --- | --- |
| DVR-плеер не включился, но в углу есть кнопка DVR | Не удалось запустить ни запись, ни live-буфер: канал офлайн, реклама, сеть или Twitch изменил API | Нажмите DVR позже; проверьте консоль `[TwitchDVR]` и обновление расширения |
| На канале без VOD плеер появился не сразу | Идёт рекламный блок Twitch — расширение ждёт контент, чтобы не начинать буфер с рекламы | Подождите окончания рекламы; обычно это 15–45 секунд |
| Во время просмотра появилась «РЕКЛАМА» или пауза | Начался рекламный блок Twitch; в локальном буфере реклама пропускается | Дождитесь продолжения или перемотайте назад — сохранённый контент остаётся доступен |
| После перезагрузки пропала история | Локальный live-буфер не переносится между сессиями и хранится только пока открыта вкладка | Это ожидаемо; для полной истории нужен VOD или внешний рекордер |
| Нет кнопки DVR в нативной панели | Twitch изменил панель или она ещё не отрисована | Используйте запасную кнопку DVR в правом верхнем углу; проверьте обновление |
| Долгий спиннер при запуске | Скачивается первый тяжёлый source-сегмент, запись догоняет эфир или ждём конец рекламы | Подождите несколько секунд; при медленной сети выберите 720p60 |
| Видео подтормаживает | Source 1080p60 требует стабильные ~8 Мбит/с | Выберите качество ниже в меню |
| Мало места на диске | Локальный буфер хранится в браузере | Уменьшите размер буфера в настройках до 5 минут или переключитесь на стандартный плеер |
| Нет звука после запуска | Браузер заблокировал автозапуск со звуком | Нажмите «Включить звук» в плеере |
| Старый интерфейс или нет новой кнопки DVR | Браузер оставил старую unpacked-версию | Обновите карточку расширения, затем `Ctrl+F5`; при необходимости удалите и загрузите заново |
| Ничего не происходит | Расширение выключено, открыт не канал или стрим офлайн | Проверьте страницу расширений Chromium (`chrome://extensions`), откройте корень канала и обновите страницу |

Если ошибка повторяется, откройте DevTools (`F12`) → Console и отфильтруйте сообщения по `[TwitchDVR]`. При создании issue приложите версию браузера, версию расширения, название канала и текст ошибки. Не прикладывайте cookies, токены и другие приватные данные.

## FAQ

<details>
<summary>Почему в России доступно 1080p, если live-плеер ограничен 720p?</summary>

Расширение воспроизводит не прямой live-поток, а запись текущей трансляции. Запись отдаёт source-дорожку, которая не попадает под ограничение live-качества. Это не VPN и не прокси: используется тот же контент, который Twitch хранит для VOD. Если записи отключены, source недоступен — локальный буфер работает в live-качестве.
</details>

<details>
<summary>Почему видео отстаёт от чата?</summary>

Запись трансляции появляется на несколько секунд позже live. Вместе с сегментом буфера задержка обычно составляет 15–30 секунд. Зато доступны source-качество и перемотка на любой момент эфира.
</details>

<details>
<summary>Можно ли смотреть 2K или 4K?</summary>

Только если стример сам ведёт трансляцию в 2K/4K и Twitch отдаёт это в source. Отдельных 2K-транскодов Twitch обычно не создаёт.
</details>

<details>
<summary>Почему DVR не работает на конкретном канале?</summary>

Если записи отключены или доступны только подписчикам, расширение включает локальный live-буфер. Если и его запустить не удалось (канал офлайн, идёт реклама, сеть или изменился API Twitch), остаётся стандартный плеер и кнопка DVR для повторной попытки.
</details>

<details>
<summary>Можно ли мотать, если стример не сохраняет записи?</summary>

Да, но только с момента открытия канала: расширение само скачивает live-сегменты и хранит их локально. История ограничена размером буфера (5–30 минут) и начинается с момента входа. Полную историю эфира без VOD можно получить только внешним рекордером, который работает с самого начала трансляции.
</details>

<details>
<summary>Почему во время рекламы видео ждёт?</summary>

Рекламные вставки Twitch не сохраняются в локальный буфер и пропускаются. Пока рекламный блок идёт в эфире, нового контента ещё нет — плеер доигрывает сохранённое и ждёт продолжения. После рекламы DVR возвращается к эфиру; если вы были перемотаны, сохранённый контент остаётся доступен.
</details>

<details>
<summary>Реклама и расширения Twitch будут работать?</summary>

Рекламные вставки в локальном режиме пропускаются. Оверлеи расширений Twitch, опросы, клипы поверх видео и другие слои стандартного плеера не отображаются: это отдельный плеер, а не оверлей Twitch. Для них переключитесь на стандартный плеер через настройки.
</details>

<details>
<summary>Нужен ли аккаунт Twitch?</summary>

Для публичных трансляций и записей — нет. Для записей «только для подписчиков» потребуется авторизация, но расширение такие записи не поддерживает.
</details>

<details>
<summary>Это безопасно?</summary>

Да: исходный код открыт, расширение не содержит аналитики и не отправляет данные третьим лицам. Все запросы идут к Twitch (gql.twitch.tv и CDN Twitch). Подробности — в разделе [Приватность и безопасность](#приватность-и-безопасность).
</details>

## Приватность и безопасность

- **Нет телеметрии и аналитики.** Расширение не отправляет данные на сторонние серверы.
- **Только Twitch.** Запросы идут к `gql.twitch.tv`, `usher.ttvnw.net` и CDN Twitch; используются публичные playback-токены, без доступа к паролю и cookies аккаунта.
- **Локальные настройки.** Выбранное качество, громкость, размер буфера и режим плеера хранятся в `localStorage` на `twitch.tv`.
- **Локальный буфер.** В режиме без VOD live-сегменты временно хранятся в IndexedDB на `twitch.tv`. Они удаляются после завершения сессии; остатки вычищаются фоновой очисткой.
- **Без удалённого кода.** Все скрипты поставляются в репозитории; расширение не загружает и не исполняет код извне.
- **Минимум разрешений.** Content script работает только на `www.twitch.tv`; широкие разрешения браузера не запрашиваются.
- **Открытый код.** Лицензия MIT — можно проверить каждую строку и собрать свою версию.

Twitch и логотип Twitch являются товарными знаками Twitch Interactive, Inc. Проект не связан с Twitch Interactive и не одобрен ею.

## Разработка

Для использования расширения сборка не нужна: достаточно загрузить папку через **Load unpacked**.

- **JS и манифест** — изменения подхватываются после перезагрузки расширения и страницы.
- **CSS** — после правок в `src/styles.css` обязательно пересоберите встроенный фолбэк:

```bash
node scripts/build-css.mjs
```

- `src/styles-inline.js` генерируется автоматически; не редактируйте его вручную.
- Зависимостей и `npm install` нет. Node нужен только для скрипта пересборки CSS.
- Отладка: DevTools → Console, фильтр `[TwitchDVR]`.
- Ручная проверка перед релизом: кнопка DVR в нативной панели, source-качество, перемотка, возврат к live, локальный буфер на канале без VOD, пропуск рекламы, уровни звука, переход на стандартный плеер.
